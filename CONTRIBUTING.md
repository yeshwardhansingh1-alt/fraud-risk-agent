# Contributing to Fraud Risk Agent

Thank you for your interest in contributing! 

## Development Setup

1. Clone the repository
2. Install dependencies: `pip install -e .`
3. Run the tests: `pytest tests/`

## Guidelines

- Add unit tests for any new functionality in the `tests/` directory.
- Use type hints for all new Python code.
- Format code according to standard PEP 8 guidelines.
- Update the `README.md` and any relevant documentation if you change the architecture or metrics.

## Submitting Changes

1. Fork the repo and create your branch from `main`.
2. Make your changes and commit them.
3. Push to your fork and submit a pull request.
